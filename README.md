# Fitcheck - AI Outfit Try-On & Style Recommendation Platform

Fitcheck is a college minor project web application that allows users to upload their photos and outfit images to generate a realistic visualization of the outfit on them, along with personalized style insights.

## Project Structure
This repository contains a monorepo setup:
- `frontend`: Next.js (App Router), React, Tailwind CSS, TypeScript
- `backend`: Node.js, Express.js, MongoDB
- `docs`: Project documentation
